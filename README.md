# 株式分析メモ

初心者向けの、シンプルな株式分析メモ Web アプリです。
銘柄コード・銘柄名・購入価格・現在価格・メモを登録すると、損益率を自動で計算して表示します。

## 特徴

- iPhone でも見やすいモバイルファースト UI
- 損益率(%)の自動計算 / プラスは緑・マイナスは赤で表示
- データはブラウザの `localStorage` に保存(サーバー不要)
- ビルドツール不要。HTML / CSS / JavaScript の3ファイル構成

## 使い方

1. このリポジトリをクローン、または ZIP でダウンロードします
2. `index.html` をブラウザで開くだけで動きます
3. iPhone で試す場合は、PC でローカルサーバーを起動して同じ Wi-Fi からアクセスすると便利です
   ```sh
   # 例: Python 3 が入っているなら
   python3 -m http.server 8000
   ```
   その後 `http://<PCのIPアドレス>:8000` を iPhone のブラウザで開きます

## ファイル構成

| ファイル              | 役割                                              |
| --------------------- | ------------------------------------------------- |
| `index.html`          | 損益メモ画面の構造                                |
| `app.js`              | 損益メモのロジック                                |
| `analysis.html`       | 銘柄分析画面の構造(新規)                        |
| `analysis.js`         | 銘柄分析のロジック(API呼び出し・計算・描画)     |
| `analysis-api.js`     | 株価API のラッパー(差し替え用に独立)            |
| `style.css`           | 両画面共通の見た目。`:root` 変数で色を一括管理    |

## 銘柄分析ページ(analysis.html)について

日本株の銘柄コードを入れると、現在株価と時価総額をネット経由で取得し、
入力した **予想PER × 予想EPS** から 1年後・2年後の理論株価を計算します。

### 初回セットアップ:APIキーの取得

株価データは [Twelve Data](https://twelvedata.com) から取得します。
無料プランで日本株(`7203.T` 等)を扱えます。

1. Twelve Data に無料登録(メール+パスワード)
2. ダッシュボードで **API Key** をコピー
3. `analysis.html` を開き、上部「API設定」にキーを貼り付けて保存

キーはブラウザの `localStorage` にのみ保存され、外部には送信しません。

### 使い方

1. 銘柄コード(例: `7203`)を入力 → 「株価を取得」
2. 現在株価・時価総額が表示される
3. 「予想PER」「1年後 予想EPS」「2年後 予想EPS」を入力 → 自動で将来株価が計算
4. 「この銘柄を保存」で `localStorage` に保存。一覧から再表示できる

## カスタマイズのヒント

- **色を変えたい**: `style.css` の `:root { ... }` の変数を変更
- **保存先を変えたい**: `app.js` / `analysis.js` の `load*` / `save*` を書き換え
- **損益率の計算式を変えたい**: `app.js` の `calcProfitRate` を編集
- **将来株価の計算式を変えたい**: `analysis.js` の `calcFuturePrice` を編集
- **株価APIを差し替えたい**: `analysis-api.js` の `fetchStockQuote` だけを書き換える
  (例: Alpha Vantage / Finnhub などに差し替え可能)
